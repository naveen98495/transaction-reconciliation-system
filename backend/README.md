# Reconciliation System

## Tech Stack
- Java
- Spring Boot
- PostgreSQL (Neon)
- Docker
- Postman

## Features
- Add Transactions
- Get Transactions
- Update Transactions
- Delete Transactions
- Reconciliation Matching
- Audit Fields

## API Endpoints

### GET
/transactions

### POST
/transactions

### PUT
/transactions/{id}

### DELETE
/transactions/{id}

## Docker Run

```bash
docker compose up --build
```
